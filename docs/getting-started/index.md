# Getting started

Nanocoder Desktop runs the Nanocoder that ships inside the app. You do not install Nanocoder separately.

You need:

- an installer for your platform, from [GitHub Releases](https://github.com/Nano-Collective/nanocoder-desktop/releases) ([installation](installation.md));
- a provider and model configured in Nanocoder's own configuration, because the desktop never stores provider keys ([setup](setup.md));
- a project folder to work in.
