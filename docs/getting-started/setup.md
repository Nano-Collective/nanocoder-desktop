# Setup

## Provider and model

Nanocoder owns its models and provider keys. Configure them in Nanocoder's own configuration, as you would for the command line tool. The desktop reads the model and mode choices Nanocoder offers and does not keep provider keys of its own.

## Open a project

Choose a project folder in the app. Nanocoder asks whether you trust the folder before it works there, and the desktop only records that trust after you confirm it. Each project keeps its own chats, and you can close the app and continue the same chat later.
