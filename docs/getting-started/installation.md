# Installation

Builds are published as alpha prereleases on [GitHub Releases](https://github.com/Nano-Collective/nanocoder-desktop/releases). Each release lists a checksum for every installer.

Installers are planned for macOS (`.dmg` and `.zip`), Windows and Linux. No release has been published yet, so check the releases page for what exists.

## Unsigned builds

Alpha installers are not signed or notarised. Expect an operating system warning when you open one: Gatekeeper on macOS and SmartScreen on Windows. Check the installer against its published checksum before you open it.

Signing is planned and tracked in the [roadmap](https://github.com/Nano-Collective/nanocoder-desktop/blob/main/planning/roadmap.md).
