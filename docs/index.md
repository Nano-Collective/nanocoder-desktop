# Nanocoder Desktop

Built by the [Nano Collective](https://nanocollective.org) — a community collective building AI tooling not for profit, but for the community.

Nanocoder Desktop is a local-first desktop workspace around [Nanocoder](https://github.com/Nano-Collective/nanocoder): durable project chats, file browsing, Git review, a terminal and an isolated browser the agent can use.

> [!NOTE]
> **Pre-v0.1.** There is no stable release, stability is not promised, and anything here can change.

It does not add a second agent. Nanocoder keeps its models, prompts, tools, approvals, MCP servers and chat history; the desktop is the workspace around it.
